# 📘 Phase 3: Research Gap Identification and Extension

## 🗓 Deadline
**3rd April**

## 🎯 Marks
**10 Marks**

---

## 📌 Task
Identify a limitation in the original research paper and propose an improved solution.

---

## 🧠 Expected Work

- Clearly define the **research gap** in the selected paper  
- Propose and implement **one improvement**, supported by references from existing literature  
- Perform **experimental comparison**:
  - Before improvement (baseline)
  - After improvement (proposed method)

---

## 📦 Deliverables

- ✅ Updated code implementation  
- 📊 Experimental results (graphs / tables)  
- 📝 1-page explanation of the research gap and proposed solution

## ⚖️ Academic Integrity and AI Usage Policy

### 🤖 AI Tools (e.g., ChatGPT, Copilot)

Allowed only if:
- Usage is **clearly declared**
- Prompts are **documented**
- Outputs are **verified and understood**

### 📄 AI Usage Documentation

Each team must submit an `AI_USAGE.md` file including:
- Tool(s) used  
- Prompts used  
- Description of how outputs were modified

## 🚫 Plagiarism Policy

- Final research paper similarity must be **less than 20%**  
- All sources must be **properly cited**  
- Copying code without citation is **strictly prohibited**  

**Violation will result in zero marks**

## 🔁 Reproducibility Requirement

Each project must include:

- 🔗 GitHub repository

- 📊 Dataset link  
- ▶️ Instructions to run the code  
- 🎲 Random seed used in experiments  

---

## 💡 Simple Understanding (First Principles)

Think of this phase like this:

- **Step 1:** Understand what the paper did  
- **Step 2:** Ask → *“What is missing or weak here?”*  
- **Step 3:** Improve it using a smart idea  
- **Step 4:** Prove your idea works better with experiments  

---

## 🌍 Real-Life Example

Imagine a paper builds a **spam email detector**:

- ❌ Limitation: Works only for English emails  
- ✅ Your improvement: Add multilingual support using better NLP models  
- 📊 Compare:
  - Old accuracy: 75%  
  - New accuracy: 88%  

👉 This is exactly what this phase expects!
